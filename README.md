

## 使い方 (`main.py`)

プログラムを起動するには、以下のコマンドを実行します。

```bash
python main.py
```

起動するとメニューが表示されます。それぞれの選択肢の詳細は以下の通りです。

### 1. Generate a monochrome ASCII ART（モノクロアスキーアート生成）
- **説明**: 画像ファイル（JPG, PNG, WEBP）を読み込み、モノクロ（白黒）のアスキーアートを生成・表示します。
- **特徴**: サイズ変更や文字の濃淡（文字セット）の選択、結果のテキストファイル保存（`generated-art.txt`）が可能です。

### 2. Generate a color ASCII ART（カラーアスキーアート生成）
- **説明**: 画像ファイルをカラーのアスキーアートに変換します。
- **特徴**: お使いのターミナル環境に合わせてカラーモード（`True Color`：iTerm2やPyCharmなど / `RGB`：標準ターミナルなど）を選択できます。

### 3. Play a gif file with ASCII ART（GIF動画再生）
- **説明**: GIF動画ファイルを読み込み、ターミナル上でアスキーアートとしてアニメーション再生します。
- **特徴**: フレームのスキップ数（再生速度）の調整が可能です。（停止するには `Ctrl + C` を押します）

### 4. Convert ASCII ART to png file（アスキーアートから画像への変換）
- **説明**: アスキーアートのテキストファイル（`.txt`）を読み込み、グレースケールのPNG画像（`Generated-photos.png`）として復元します。
- **特徴**: 生成時に使用された文字セット（Normal, Block, Impact）に合わせた復元を行います。

### 5. Chat with other people by using achex（チャット機能）
- **説明**: WebSocketを利用したチャットルームに参加し、他のユーザーとメッセージやファイルをやり取りできます。
- **特徴**: 
  - ルーム名とパスワードを設定して入室します。
  - チャット中に `/generate` コマンドで即座にアスキーアートを生成・共有したり、`/file` コマンドでテキストファイルを送信、`/download` で相手の共有したファイルを保存できます。
  - 利用可能なコマンド一覧はチャット内で `/cmd` と入力すると確認できます。

---

## ⚠️ WebSocket ("achex") に関する注意点

チャット機能（メニュー5）では、パブリックなWebSocketサービスである **`achex`** (`wss://cloud.achex.ca/chat`) を利用しています。

- **匿名性とセキュリティについて**:
  起動時に `This chat's anonymity is low.` と表示される通り、このサービスを利用した通信やデータの秘匿性・匿名性は高くありません。
  **パスワード付きのルームであっても、第三者に傍受されるリスクやサーバー側にデータが経由する可能性があるため、機密情報、個人情報、パスワードなどのプライベートな情報は絶対に送信しないようご注意ください。**
