# ASCII ART CHAT
特徴 コマンド ギャラリー GitHub

ブラウザだけで動く ASCII ART チャット

文字で描いて、
そのまま話す。

画像をその場で ASCII ART に変換して送れるチャットです。インストールも登録も不要で、 python main.py のメニュー5 と同じ部屋に混ざって会話できます。

  • インストール不要
  • Python版と相互接続
  • 画像→ASCII ARTを即送信
  • HEIC (iPhoneの写真) 対応
下へスクロールして使い方を見る ↓

部屋に参加する

Achex を使ったチャットです。python main.py のメニュー5 と同じ部屋に参加できます。

匿名性は低いです。パスワードや個人情報を送らないでください。
パスワード付きのルームであっても、第三者に傍受されるリスクやサーバー側にデータが経由する可能性があります。
通信は TLS で暗号化され証明書も検証されますが、Achex が対応する暗号方式の都合で前方秘匿性はありません (サーバーの秘密鍵が将来漏れると、記録された過去の通信が復号され得ます)。

最初に参加する人は部屋IDとパスワードは何でも構いません。同じ部屋に入るには、全員が同じ値を入力してください。

できること

◇

インストール不要

ブラウザでこのページを開くだけで参加できます。PythonもNode.jsも要りません。スマートフォンでも動きます。

◆

Python版と同じ部屋

部屋IDとパスワードを合わせれば、ターミナルの参加者とブラウザの参加者が同じ部屋で会話できます。

▧

画像をその場で変換

/generate で画像を白黒/カラーの ASCII ART にして送信。iPhone の HEIC もそのまま扱えます。/download で画像に戻すこともできます。

コマンド

入室後、メッセージ欄に入力します。チャット中に /cmd と打つと同じ一覧を表示できます。

コマンド説明

ブラウザにはファイルパスが無いため、/generate と /file はパスを取りません。 画像やテキストファイルは画面にドラッグ&ドロップしておくか、コマンド実行時に開くファイル選択ダイアログから指定します。 JPEG・PNG・WEBP のほか HEIC (iPhoneの写真) も変換できます (HEIC を選んだときだけ復号用のデータを読み込むため、最初の1回は少し時間がかかります)。 1回に500KBを超えるデータは送信できません。
